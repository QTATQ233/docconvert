# examples/ 输入样本索引

本目录是 docconvert 的测试输入样本，供开发自测（阶段 2）与验收（阶段 3）复用。所有样本都是**真实可读**的文档，不是占位符；数据类内容均标注为"示例数据"，不得作为科研引用。

| 文件 | 覆盖的排版要素 | 期望页数（默认模板，估算） | 关联用例 |
| --- | --- | --- | --- |
| `headings.md` | 3 级标题层级（另含 1 个 H4）、无序列表、行内代码 | 3–4 页 | TC-H-01 / TC-H-02 |
| `table.md` | 8 列宽表（6 行）+ 8 列长表（60 行，跨页） | 3–5 页 | TC-TB-01 / TC-TB-02 |
| `code.md` | 代码块（js/ts/json/powershell/text）、超长单行、制表符 | 2–3 页 | TC-CD-01 / TC-CD-02 |
| `image.md` | 相对路径图片 ×4：过宽、过高、小图、流程图 | 3–4 页 | TC-IM-01 / TC-IM-02 |
| `cjk.md` | 中英混排、中文标点、强调、链接、引用块、嵌套列表、长英文词 | 3–4 页 | TC-CJ-01 / TC-CJ-02 |

## 约定

1. **相对路径解析**：`image.md` 里的 `assets/*.png` 是相对于该 `.md` 文件所在目录的。执行时不要把输入文件复制到别处再转换，否则图片会丢失——这是 TC-IM-03 的判定点。
2. **不要提交输出**：所有用例的输出目录统一放在 `out/`（已被 .gitignore 覆盖；若未覆盖，由实现者补上）。
3. **样本修改规则**：任何人改动本目录的样本文件，必须同步更新本索引与 `test-cases.md` 中的期望值（标题数、表行数、页数区间），并在 test-report 记录变更原因。
4. **页数不是硬编码的 golden**：默认模板定稿后若页数变化，以"区间"判定；只有 `long-50.md` 的"≥ 50 页"是硬指标。
