# 城市湿地公园观测手册

本手册用于指导志愿者在城市湿地公园开展常态化的鸟类与生境观测，覆盖前期准备、外业记录与内业整理三个阶段。手册中的样区编号、观测时段与记录格式均与本市湿地监测平台的字段保持一致，填写后可直接导入平台。

## 手册使用说明

每次外业前通读一遍本节的准备清单，外业结束后按第三章的格式整理记录。手册中的表格可以直接复印使用，也可以在现场用平板填写后导出。

### 记录方式

现场记录采用"先速记、后补全"的方式：用铅笔在防水记录卡上写下时间、物种与数量，回到室内再誊写到正式表格。所有原始记录卡需保留至季度审核结束，不得丢弃或覆盖。

### 器材清单

- 双筒望远镜（8×42 或 10×42）一副，出发前检查镜片与背带
- 单筒望远镜（20–60 倍）与三脚架，供开阔水面计数使用
- 防水记录卡、2B 铅笔、橡皮、硬质垫板
- 手持 GPS 或已下载离线地图的手机
- 鸟类图鉴一本，用于现场核对形态特征
- 急救包与驱蚊用品，夏季必备

### 安全须知

滩涂与栈道湿滑，禁止单独进入未开放区域。观测水鸟时与巢区保持三十米以上距离，不得播放鸣声回放引诱鸟类，不得投喂。遇到受伤个体，记录位置后联系公园管理处，不要自行捕捉。

# 第一章 湿地类型与分区

城市湿地公园通常由人工水面、自然滩涂、挺水植物带与陆域缓冲带组成。分区观测有助于把物种记录与生境条件对应起来，避免出现"某处见到某鸟"却无法解释的记录。

## 1.1 水域与滩涂

水域按水流状态分为静水区与流水区。静水区包括人工湖、沉淀塘与季节性水洼；流水区包括入水口、溢流堰与连通河道。

### 1.1.1 静水区

静水区水面平静，适合用样点法统计游禽与涉禽。清晨逆光时水面反光强，建议站在背光侧观察；午后风起，波纹会干扰对潜水的判断，可改用单筒望远镜分区扫描。

### 1.1.2 流水区

流水区水位变化快，雨后两小时内不宜进入。此处常见的是喜欢活水的种类，记录时应同时注明水位与流速的目测等级，便于后续解释数量的波动。

## 1.2 挺水植物带

挺水植物带是隐蔽与营巢的主要场所，芦苇、香蒲与菖蒲构成的主体植被决定了鸟类的组成。

### 1.2.1 芦苇群落

芦苇区视野差，靠听声辨认效率更高。记录时把"听到但未见到"的个体单独标记，不要与目击个体混在一起统计，否则会高估种群数量。

### 1.2.2 香蒲群落

香蒲群落面积通常较小，但边缘效应明显。沿群落边缘走一条二十米的短样线，往往能记录到在芦苇区不易发现的种类。

# 第二章 鸟类观测方法

本章规定两种基本方法：样线法用于陆域与林缘，样点法用于开阔水面。两种方法的记录单位不同，汇总时不得直接相加。

## 2.1 样线法

样线法沿固定路线匀速行走，记录路线两侧一定范围内的个体。路线一经确定，本季度内不得随意改动，以免破坏数据的可比性。

### 2.1.1 样线布设

样线长度以一到两公里为宜，起点与终点需有明显地标。布设时避开车行道与游人密集区，若无法避开，应在记录中注明干扰等级。

### 2.1.2 记录频次

繁殖季每周一次，越冬期每两周一次，每次观测安排在日出后三小时内完成。同一季度内的观测应尽量固定在一天中的同一时段，减少活动节律带来的偏差。

## 2.2 样点法

样点法在固定点位停留固定时长，统计点位周围一定半径内的个体。它适合水面开阔、行走困难的区域。

### 2.2.1 样点选择

样点应覆盖不同的水深与植被盖度，相邻样点间距不小于两百米，避免重复计数同一批个体。

### 2.2.2 计时规则

到达样点后先静立两分钟，待惊飞的个体落定再开始计时。计时期间只记录进入视野的个体，不追逐、不移动位置。

### 2.2.3 常见误差

常见误差包括：把同一只鸟在相邻样点重复记录、把飞行中的个体误计入点位、以及在雨雾天气高估隐蔽物种的缺失。发现异常应在备注栏写明原因，而不是事后修改数字。

# 第三章 数据整理与提交

外业结束后四十八小时内完成整理。整理的核心是把现场速记转换成平台可导入的结构化表格，并保留可追溯的原始记录。

## 3.1 表格填写

表格按"一条记录一行"的原则填写，不得合并单元格。物种名称使用平台名录中的中文名，学名写在括号内；数量为估计值时，在备注中写明估计方法。

## 3.2 照片归档

照片用于佐证罕见记录与异常生境，不作为计数的唯一依据。归档时按"日期_样区_序号"命名，并保留原始文件，不得压缩后覆盖。

### 3.2.1 命名规范

例如 `20261018_A2_003.jpg` 表示十月十八日在 A2 样区拍摄的第三张照片。命名不使用空格与中文标点，避免跨平台传输时出现乱码。

### 3.2.2 元数据

照片的拍摄时间与坐标由设备自动写入，导出时不要剥离。若使用截图或翻拍，需在备注中说明来源，并注明原始记录的存放位置。

#### 归档目录示例

推荐按"年份/季度/样区"三级目录存放，目录名使用阿拉伯数字与字母，不使用特殊符号。季度目录内另建 `raw` 与 `final` 两个子目录，分别存放原始文件与整理后的提交版本。
